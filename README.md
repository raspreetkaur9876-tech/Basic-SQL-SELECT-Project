# Basic SQL SELECT Project

## Project Overview
This is a beginner-friendly SQL project created using MySQL Workbench. It demonstrates basic SQL operations using a sample Sales database.

## Objectives
- Understand SQL database creation.
- Create and manage tables.
- Retrieve data using SELECT.
- Filter records using WHERE.
- Sort records using ORDER BY.

## Tools Used
- MySQL Workbench
- SQL

## Database Details
**Database Name:** Basic_SQL_Project

**Table Name:** Sales

**Columns:**
- OrderID
- CustomerName
- Product
- Category
- City
- Quantity
- Price

## SQL Queries Performed
1. Display all records.
2. Display customer names.
3. Display product names.
4. Find orders from Delhi.
5. Find Electronics products.
6. Find quantity greater than 3.
7. Sort products by price (Ascending).
8. Sort products by price (Descending).
9. Find orders with price greater than 5000.
10. Sort customers alphabetically.
